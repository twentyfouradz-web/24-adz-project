PROJECT IDENTITY
This package is the 24Adz.com project. No separate Hey Mr website homepage,
admin panel, frontend bundle, or active legacy authentication implementation
was found in the supplied source package.

- public/sitemap.xml: public sitemap.

resource is currently named hey-mr-images. These are existing Cloudflare resource
identifiers, not evidence of old website frontend code. They are intentionally
preserved because the current Worker configuration depends on them. Do not
rename, delete, or replace these resources as part of source cleanup.
