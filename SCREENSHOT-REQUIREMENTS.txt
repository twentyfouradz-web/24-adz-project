HEY... MR — UPDATED PROJECT REQUIREMENTS

1. Admin + Client Ads Posting
   - Authenticated Admin can create, edit, publish, pause, or delete all advertisements.
   - Authenticated, email-verified Clients can create advertisements.
   - Clients can edit/delete only ads owned by their own account; ownership is enforced server-side.
   - Public visitors can browse/search/filter but cannot create or manage ads.

2. Client Browsing and Search
   - Public clients can browse published advertisements.
   - Public clients can search/filter advertisements and open listing details.
   - Public clients cannot create or manage advertisements.

3. Contact Methods
   - Listing cards expose Call and WhatsApp only.
   - Contact buttons remain controlled by Admin website settings.
   - No internal Chat Messenger contact option is offered.

4. Chat Messenger
   - Provide client inbox, per-ad conversation threads, Admin replies and periodic live updates.
   - Protect every conversation by authenticated participant/Admin access.

5. Preserve Existing Project
   - Keep existing homepage design and existing non-chat features.
   - Keep Admin Panel, categories, districts, form builder, VIP settings, D1 and R2 integrations.

5. Verification and Security
   - Email verification and email password reset are required.
   - Mobile OTP / SMS verification is explicitly excluded.
   - Add rate limits, spam/fake-account controls and browser testing.
