SECURITY / PERMISSIONS
- Admin can create and manage all ads using Admin APIs.
- Email-verified clients can create ads and manage only ads owned by their account.
- Public visitors can browse/search/filter published ads but cannot create or manage ads.
- Email verification is required for client login and client API access.
- Mobile OTP/SMS verification is not implemented or required. Mobile number is a contact field only.
- Admin APIs require an Admin bearer token.
- Client APIs require a valid Client bearer token for an email-verified account.
- Images are stored in the configured R2 bucket (max 5 MB; supported image formats validated by the Worker).

MIGRATIONS
- Migration files are ordered history. Apply only migrations that are not already applied.
- Back up D1 before production migrations.
- Confirm `database_name` and `database_id` in wrangler.toml identify the intended database before any remote migration.

CLIENT FRONTEND
- /client.html : Client registration, email verification, login, dashboard, own ads, profile, messages and coin requests.
